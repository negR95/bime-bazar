# Bime Bazar - Interview Task 

This project was developed as a frontend interview task for Bime Bazar. It aims to provide a clean, maintainable, and scalable architecture by utilizing modern tools and adhering to best practices.

## Tech Stack

- **Framework:** [Next.js (v16)] / [React (v19)]
- **Language:** [TypeScript]
- **Styling:** [Tailwind CSS (v4)] + `tailwind-merge`
- **Form Management & Validation:** [Formik] + [Yup]
- **API Client:** [Axios]
- **Linter & Formatter:** [Biome]

## Getting Started

Follow these instructions to get the project up and running on your local machine:

### Prerequisites
Make sure you have [Node.js](version 20 or higher) and [pnpm] installed on your system.

### Installation & Execution

1. Clone the repository or extract the project files.
2. Install the dependencies:

```bash
pnpm install
```

3. Run the development server:

bash
pnpm dev

4. Open [http://localhost:3000] in your browser to see the result.

## Available Scripts

The following scripts are available in the project for your convenience:

- `pnpm dev`: Runs the app in development mode.
- `pnpm build`: Builds the app for production.
- `pnpm start`: Starts the production server.
- `pnpm lint`: Checks the code for syntax and styling issues (using Biome).
- `pnpm format`: Automatically formats the codebase (using Biome).
